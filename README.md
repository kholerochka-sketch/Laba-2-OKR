# 🏔️ Карпати без натовпу

**«Карпати без натовпу»** — це вебдодаток для пошуку, перегляду та керування затишними, маловідомими локаціями в Карпатах для відпочинку подалі від туристів.

---

## 🛠️ Технологічний стек

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **Backend:** .NET (C#), REST API, Swagger, Global Exception Middleware
- **Database:** MongoDB
- **DevOps & Tools:** Docker, Git / GitHub, Trello

---

## ✨ Основні можливості

- **Перегляд локацій:** Зручний каталог із картками місць, описом, порадами та цінами.
- **Інтерактивний інтерфейс:** Пошук та фільтрація локацій без перезавантаження сторінки.
- **Захищена адмін-панель:** 
  * Вхід за закритим ключем доступу (`AdminKey`).
  * Форма додавання нових туристичних місць.
  * Динамічне малювання та обробка кнопок видалення `🗑️` із захистом запитів через заголовок `X-Admin-Key`.

---
